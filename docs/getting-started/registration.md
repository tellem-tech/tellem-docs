# Подключение и первый вход { #connection-and-first-sign-in }

Создайте подписку и получите доступ к CRM, затем перейдите к настройке магазина.

<span id="_2"></span>

## Личный кабинет { #personal-account }

1. Откройте [tellem.tech/lk](https://tellem.tech/lk). Для регистрации по почте нажмите «Нет аккаунта? Зарегистрируйтесь». Укажите имя, фамилию и почту, отметьте согласие на обработку персональных данных и нажмите «Создать аккаунт». Введите код из письма и нажмите «Подтвердить». Войти можно также через Яндекс или VK ID.
2. В разделе «Подписки» нажмите «Подключить подписку» и выберите тариф. В поле «Адрес магазина» введите от 1 до 63 строчных латинских букв, цифр или дефисов. Дефис допустим только внутри имени. Например, для адреса `myshop.tellem.store` введите `myshop`.
3. Нажмите «Продолжить», затем кнопку оплаты. Оплатите подписку в новой вкладке. Вернитесь в личный кабинет и нажмите «Обновить статус».

Если вы закрыли вкладку до оплаты, вернитесь к карточке подписки со статусом «Ждёт оплаты» и нажмите кнопку оплаты. После оплаты магазин запускается автоматически. Когда он будет готов, на карточке появятся кнопки «Открыть CRM» и «Открыть магазин».

!!! note "Доступ в CRM"
    Данные для входа в CRM пришлёт команда Tellem. Для добавления сотрудников тоже обратитесь в [поддержку Tellem](https://t.me/tellem_tech_bot).

<span id="crm"></span>

## Вход в CRM { #signing-in-to-the-crm }

Откройте `https://<поддомен>.tellem.store/crm` (или «Открыть CRM» в личном кабинете), введите «Логин» и «Пароль» и нажмите «Войти».

Кнопки восстановления пароля нет: если пароль утерян, напишите в [поддержку Tellem](https://t.me/tellem_tech_bot).

Чтобы сменить пароль, откройте **меню пользователя в шапке → Профиль → Пароль**, введите новый пароль и подтверждение, затем нажмите «Сохранить».

Чтобы открыть личный кабинет в новой вкладке, выберите **меню пользователя в шапке → Личный кабинет**.

Если в шапке появился замок, нажмите его, чтобы прочитать причину ограничения доступа. В этом окне также можно открыть личный кабинет или обратиться в поддержку.

## Мастер «Приветственная конфигурация» { #welcome-configuration-wizard }

При первом входе заполните мастер и нажмите «Завершить». Пока мастер не завершён, он открывается при каждой загрузке CRM у всех сотрудников. В каждом вопросе выберите хотя бы один вариант.
