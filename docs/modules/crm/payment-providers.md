# Оплата { #payment }

Подключите онлайн-оплату или предложите покупателю оплатить заказ при получении.

Откройте **Настройки → Оплата**.

<span id="_2"></span>

## Создание способа { #creating-a-method }

1. Нажмите **Новый сервис**, выберите провайдера и введите реквизиты из его кабинета. Наименование видно покупателю и должно быть уникальным.
2. При необходимости задайте комиссию и срок ожидания платежа. Комиссия увеличивает стоимость товаров, но не доставки; у Альфа банка её нет. После истечения срока неоплаченный заказ получает **Ошибка оплаты** с задержкой.
3. На вкладке **Поля заказа** настройте видимость и обязательность контактов. Почта обязательна у Т-Банка и СБП (Т-Банк), у Точка Банк — при фискализации, то есть выдаче кассового чека.
4. Нажмите **OK**. Для нового сервиса откроется окно **Смена активного сервиса**: **Сохранить активным** включает его во всех сетях и выключает другие сервисы того же типа. Для проверки сначала выберите **Сохранить неактивным**, затем включите способ в [нужной сети](stores-and-delivery.md).

!!! warning "Секретные реквизиты"
    Пароли, токены и секретные ключи вводите только в CRM и кабинете провайдера. Не включайте их в скриншоты и обращения в поддержку. Для уведомлений используйте адреса, показанные CRM, без изменений.

**Картой при получении** и **Наличными при получении** можно изменить, но нельзя удалить. Способ, использованный в заказах, также не удаляется.

Онлайн-оплата в Tellem доступна для заказов в рублях. Для другой валюты используйте оплату при получении.

!!! warning "Перевод онлайн"
    Приложение не показывает реквизиты для этого ранее доступного способа. Выключите его в сетях через **Каталог → Магазины → Управление способами оплаты**. Для уже созданного заказа **Новый** согласуйте оплату с покупателем и нажмите [Принять заказ](orders.md).

## Порядок способов { #method-order }

В **Настройки → Оплата** выберите строку и нажмите **Выше** или **Ниже**. На телефоне эти команды находятся в меню **Действия**. Порядок сохраняется сразу и действует во всех сетях магазинов; покупатель видит только включённые в его сети способы.

<span id="_3"></span>

## Проверка { #testing }

**Сгенерировать тестовую ссылку для оплаты** проверяет, принимает ли провайдер реквизиты. Откройте полученную страницу. Тестовая ссылка не связана с заказом и не меняет его статус в CRM.

Возврат в приложение и смену статуса проверьте настоящим заказом на согласованную небольшую сумму. До проверки не включайте способ во всех сетях. Если проверочный платёж нужно вернуть, [оформите возврат](orders.md#cancellation) отдельно.

## Особенности провайдеров { #provider-requirements }

Остальные реквизиты перенесите из кабинета выбранного сервиса.

| Сервис | Что учесть |
|---|---|
| Т-Банк, СБП (Т-Банк); Альфа банк, СБП (Альфа банк) | Необязательный префикс номера заказа: латинские буквы |
| Робокасса | Поддерживается хэш-алгоритм MD5 |
| СБП (Аркопэй) | Выберите одноразовую или многоразовую ссылку СБП |
| Сбербанк, СБП (Сбербанк) | [Получите данные интернет-терминала и настройте уведомления](#sberbank) |
| Бета трансфер | Задайте **Минимальную сумму платежа** по условиям провайдера. Она ограничивает положительный остаток после списания бонусов и не может понизить минимальный порог сервиса в CRM |
| Точка Банк, Точка Банк (СБП) | [Получите токен и выберите реквизиты](#tochka) |

<span id="_5"></span>

## Уведомления провайдера { #provider-notifications }

Перенесите адреса из CRM в кабинет провайдера:

- **ЮKassa:** **Данные для личного кабинета → URL для уведомлений**; выберите события `payment.succeeded` и `payment.canceled`.
- **Робокасса:** на той же вкладке Result URL с методом POST, Success URL и Fail URL с методом GET.
- **Бета трансфер:** Result, Success и Fail URL находятся в блоке **Дополнительная информация**.
- **Сбербанк:** адрес выдаёт поддержка Tellem. Укажите его в СберБизнесе и задайте параметры проверки в CRM, как описано в разделе [Уведомления об оплате](#sberbank-notifications).

У Т-Банка и АркоПэй адрес передаётся с платежом, у Альфа банка статус проверяется без уведомлений. У ЮKassa проверка статуса продолжается независимо от переключателя **Обновлять состояние платежей через планировщик**.

## Сбербанк и СБП (Сбербанк) { #sberbank }

Для приёма оплаты картой и через СБП нужен договор интернет-эквайринга со Сбером.

### Договор с банком { #sberbank-contract }

Для заявки подготовьте:

- название ИП или ООО и ИНН;
- имя, телефон и рабочую почту сотрудника, который будет общаться с банком;
- реквизиты расчётного счёта для зачисления выручки;
- адрес сайта магазина;
- данные действующей онлайн-кассы, если она есть.

Оставьте заявку на [сайте Сбера](https://www.sberbank.ru/ru/s_m_business/bankingservice/sberpay) или обратитесь к своему менеджеру в банке. Скажите, что нужен интернет-эквайринг для оплаты картой на сайте магазина Tellem. Если нужна оплата через СБП, попросите подключить и её.

Спросите банк, как отправлять покупателям кассовые чеки: в настройках Сбербанка в Tellem параметров чеков нет. До подписания договора уточните комиссию банка с учётом налогов, стоимость отправки чеков и сроки зачисления выручки.

!!! note "Если договор уже есть"
    Попросите банк проверить, можно ли подключить к договору сайт Tellem. Если оплата через Сбер уже работает на другом сайте, меняйте её настройки только после согласования с ответственным за тот сайт.

### Данные интернет-терминала { #sberbank-terminal }

После одобрения заявки банк подключит для сайта интернет-терминал. Найдите его в СберБизнесе — интернет-банке Сбера для бизнеса: **Эквайринг → Оборудование** → интернет-терминал. Если нужного терминала нет в списке, запросите у менеджера статус подключения и номер терминала.

На вкладке **Настройки** терминала находятся данные для Tellem:

- **Логин шлюза** — служебный логин для подключения сайта. Обычно он оканчивается на `-api`.
- **Пароль шлюза** — нажмите **Сгенерировать**, затем **Скопировать пароль** и сохраните пароль в защищённом месте. Пароль показывается один раз: после нажатия **Закрыть** его нельзя посмотреть снова.

!!! warning "Новый пароль заменяет старый"
    Если терминал уже принимает оплату на другом сайте, сначала согласуйте замену пароля: на том сайте нужно будет ввести новый пароль.

Логин и пароль для входа в СберБизнес и коды из СМС для Tellem не нужны.

Тестовые логин и пароль отличаются от рабочих. Если нужна проверка без реальных платежей, запросите их у менеджера.

Подробнее о настройках терминала — в [справке Сбера](https://www.sberbank.ru/help/business/sbbol/acquiring/work/100667).

### Уведомления об оплате { #sberbank-notifications }

Через уведомления банк сообщает Tellem об оплате заказа. Тип контрольной суммы и ключ нужны, чтобы CRM могла проверить, что уведомление отправил банк. Пока они не заданы в Tellem, CRM отклоняет уведомления банка, и статус заказа обновится только при следующей проверке платежа.

1. Запросите ссылку для уведомлений в [поддержке Tellem](https://t.me/tellem_tech_bot).
2. Запросите у менеджера банка тип контрольной суммы уведомлений и ключ для их проверки.
3. В СберБизнесе откройте интернет-терминал: **Настройки → Колбэк-уведомления → Подключить**.
4. В поле **Ссылка для уведомлений** вставьте ссылку целиком и нажмите **Подключить**. Статус должен смениться на **Подключены**.

!!! warning "Ссылка общая для терминалов мерчанта"
    Ссылка для уведомлений меняется у всех интернет-терминалов этой точки подключения (мерчанта). Если через неё уже принимает платежи другой сайт, сначала согласуйте изменение с ответственным за него.

Подробнее о колбэк-уведомлениях — в [справке Сбера](https://www.sberbank.ru/help/business/sbbol/acquiring/work/100752).

### Настройка в Tellem { #sberbank-setup }

1. В **Новый сервис** выберите **Сбербанк** для оплаты картой. Для оплаты через СБП создайте отдельный сервис **СБП (Сбербанк)**, когда банк подтвердит, что СБП подключена.
2. Заполните поля:

    | Поле | Что указать |
    |---|---|
    | **Логин**, **Пароль** | Логин и пароль шлюза из [настроек интернет-терминала](#sberbank-terminal) |
    | **Тестовый режим** | Включите для тестовых логина и пароля, выключите для рабочих |
    | **Тип контрольной суммы уведомлений** | Тип, который назвал банк: **Симметричный (HMAC-SHA256)** или **Асимметричный (SHA512withRSA)** |
    | **Ключ проверки уведомлений** | Ключ от банка: секретный ключ для симметричного типа или открытый ключ (сертификат) для асимметричного |

3. **Сгенерировать тестовую ссылку для оплаты** для **Сбербанк** открывает страницу оплаты Сбера, для **СБП (Сбербанк)** — страницу оплаты через СБП. Если вместо ссылки появилась ошибка, проверьте логин, пароль и **Тестовый режим**: тестовые данные работают только при включённом режиме, рабочие — при выключенном.
4. Перед [проверкой настоящим заказом](#testing) введите рабочие логин и пароль и выключите **Тестовый режим**. После оплаты заказ должен получить [статус «Оплачено»](orders.md#online-payment), платёж на ту же сумму — появиться в СберБизнесе, а покупатель — получить чек, если отправка чеков подключена.

Если заказ не получил статус «Оплачено», выключите способ в магазине и напишите в [поддержку Tellem](https://t.me/tellem_tech_bot). Вопросы о договоре, терминале и уведомлениях задавайте менеджеру банка или ищите ответы в [справке СберБизнеса](https://www.sberbank.ru/help/business/sbbol).

## Точка Банк и Точка Банк (СБП) { #tochka }

1. В кабинете Точки откройте **Сервисы → Все сервисы → Интеграции и API → JWT-ключи**. Создайте токен (ключ доступа) с правами для нужного продукта:

    | Продукт | Права |
    |---|---|
    | Карта | `ReadCustomerData`, `MakeAcquiringOperation`, `ReadAcquiringData`, `ManageWebhookData` |
    | СБП | `ReadCustomerData`, `ReadSBPData`, `EditSBPData`, `ManageWebhookData` |

2. Вставьте токен в **Токен доступа** без слова `Bearer`. `client_id` и логин конструктора сайтов не подходят.
3. Выберите загруженные реквизиты: для карты — компанию и торговую точку, для СБП — торговую точку и счёт. Если списки пусты, проверьте срок и права токена, тестовый режим и подключение продукта в банке.
4. Для **Публичный JWK для webhook** нажмите **Получить**. Это публичный ключ банка для проверки уведомлений. Скопируйте **URL webhook-уведомления** в интеграцию Точки и выберите событие `acquiringInternetPayment` для карты или `incomingSbpPayment` для СБП.

Для **С фискализацией** сначала подключите услугу в банке. Настройка действует на новые ссылки; почта покупателя становится обязательной. В чек входят товары с комиссией и доставка, списанные бонусы уменьшают сумму.

В **Тестовом режиме** используйте тестовые реквизиты Точки. Перед рабочими платежами выключите режим, замените токен на рабочий и заново выберите реквизиты. Затем выполните [проверку оплаты](#testing).
