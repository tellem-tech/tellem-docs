# Интеграции { #integrations }

Откройте **Интеграции** и выберите сервис, который нужен магазину.

| Сервис | Задача |
|---|---|
| AI | Чат-помощник в CRM и [подготовка текста рассылки](mass-mailings.md) |
| Telegram | [Подключение бота, входа и Mini App](../../getting-started/bot-setup.md) |
| VK | [Уведомления и рассылки от сообщества магазина](vk.md) |
| iiko | [Передача заказов, столы и стоп-листы](iiko.md) |
| Пользовательские | Действия при смене статуса заказа, настроенные командой Tellem |

При отключении Telegram или VK покупатели перестают получать сообщения в этот канал и видеть его переключатель в профиле. Другой канал сам не включается: проверьте [доступные покупателю уведомления](../app/customer-notifications.md).

## AI { #ai }

1. В **Интеграции → AI** включите **AI Интеграция**, выберите модель и вставьте API-ключ своего аккаунта OpenAI. Храните ключ в секрете.
2. Нажмите **Проверить подключение**. Настройки сохраняются сразу.
3. Обновите страницу: в шапке CRM появится **AI Чаты** со значком волшебной палочки. В рассылках станет доступно **Написать с ИИ**.

Проверяйте ответы до использования. Чаты удаляются через две недели.


В **AI Чаты** владелец может спросить, какой аудитории написать, как менялись сегменты за период
или чем отличаются результаты прошлых кампаний. Укажите точку и даты, например:
«Сравни кампании за последний месяц для этой точки и предложи рассылку для лояльных клиентов».
Помощник даёт советы и может оценить размер доступной аудитории с учётом согласий, канала и частоты.
Кампании и сегменты создайте сами в [рассылках](mass-mailings.md).

Проверяйте точку, период и даты расчёта в ответе. Пропуски истории означают нехватку данных.
Изменение размеров сегментов не показывает, кто из клиентов перешёл между ними. Покупки аудитории
после кампании сами по себе не доказывают влияние рассылки или её окупаемость.

## Пользовательские { #пользовательские }

Команда Tellem настраивает действия, которые выполняются при переходе заказа в выбранные статусы. Они могут передавать данные заказа во внешние системы. Владелец просматривает результат в **История REST запросов** у выбранной интеграции.

!!! warning "Повторное выполнение"
    **Выполнить повторно** снова запускает действие во внешней системе. Перед повтором проверьте результат первой попытки. Если интеграция выдаёт цифровые коды, проверьте **Системные атрибуты** заказа: сохранённый код можно передать покупателю вручную, не выпуская второй.
