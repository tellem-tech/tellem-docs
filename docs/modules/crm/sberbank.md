# Сбербанк { #sberbank }

Подключите интернет-эквайринг Сбербанка, чтобы покупатели оплачивали заказы на сайте картой или через СБП (Систему быстрых платежей).

## Договор с банком { #contract }

Для заявки подготовьте:

- название ИП или ООО и ИНН;
- имя, телефон и рабочую почту сотрудника, который будет общаться с банком;
- реквизиты расчётного счёта для зачисления выручки;
- адрес сайта магазина;
- данные действующей онлайн-кассы, если она есть.

Оставьте заявку на [сайте Сбера](https://www.sberbank.ru/ru/s_m_business/bankingservice/sberpay) или обратитесь к своему менеджеру в банке. Скажите, что нужен интернет-эквайринг для оплаты картой на сайте магазина Tellem. Если нужна оплата через СБП, попросите подключить и её.

Спросите банк, как отправлять покупателям кассовые чеки: в настройках Сбербанка в Tellem параметров чеков нет. До подписания договора уточните комиссию банка с учётом налогов, стоимость отправки чеков и сроки зачисления выручки.

!!! note "Если договор уже есть"
    Попросите банк проверить, можно ли подключить к договору сайт Tellem. Если оплата через Сбер уже работает на другом сайте, меняйте её настройки только после согласования с ответственным за тот сайт.

## Данные интернет-терминала { #terminal }

После одобрения заявки банк подключит для сайта интернет-терминал. Найдите его в СберБизнесе — интернет-банке Сбера для бизнеса: **Эквайринг → Оборудование** → интернет-терминал. Если нужного терминала нет в списке, запросите у менеджера статус подключения и номер терминала.

На вкладке **Настройки** терминала находятся данные для Tellem:

- **Логин шлюза** — служебный логин для подключения сайта. Обычно он оканчивается на `-api`.
- **Пароль шлюза** — нажмите **Сгенерировать**, затем **Скопировать пароль** и сохраните пароль в защищённом месте. Пароль показывается один раз: после нажатия **Закрыть** его нельзя посмотреть снова.

!!! warning "Новый пароль заменяет старый"
    Если терминал уже принимает оплату на другом сайте, сначала согласуйте замену пароля: на том сайте нужно будет ввести новый пароль.

Логин и пароль для входа в СберБизнес и коды из СМС для Tellem не нужны.

Тестовые логин и пароль отличаются от рабочих. Если нужна проверка без реальных платежей, запросите их у менеджера.

Подробнее о настройках терминала — в [справке Сбера](https://www.sberbank.ru/help/business/sbbol/acquiring/work/100667).

## Уведомления об оплате { #notifications }

Через уведомления банк сообщает Tellem об оплате заказа. Тип контрольной суммы и ключ нужны, чтобы CRM могла проверить, что уведомление отправил банк. Пока они не заданы в Tellem, CRM отклоняет уведомления банка, и статус заказа обновится только при следующей проверке платежа.

1. Запросите ссылку для уведомлений в [поддержке Tellem](https://t.me/tellem_tech_bot).
2. Запросите у менеджера банка тип контрольной суммы уведомлений и ключ для их проверки.
3. В СберБизнесе откройте интернет-терминал: **Настройки → Колбэк-уведомления → Подключить**.
4. В поле **Ссылка для уведомлений** вставьте ссылку целиком и нажмите **Подключить**. Статус должен смениться на **Подключены**.

!!! warning "Ссылка общая для терминалов мерчанта"
    Ссылка для уведомлений меняется у всех интернет-терминалов этой точки подключения (мерчанта). Если через неё уже принимает платежи другой сайт, сначала согласуйте изменение с ответственным за него.

Подробнее о колбэк-уведомлениях — в [справке Сбера](https://www.sberbank.ru/help/business/sbbol/acquiring/work/100752).

## Настройка в Tellem { #setup }

1. Откройте **Настройки → Оплата**, нажмите **Новый сервис** и выберите **Сбербанк** для оплаты картой. Для оплаты через СБП создайте отдельный сервис **СБП (Сбербанк)**, когда банк подтвердит, что СБП подключена.
2. Заполните поля:

    | Поле | Что указать |
    |---|---|
    | **Наименование** | Название способа для покупателя, например «Онлайн картой» |
    | **Логин**, **Пароль** | Логин и пароль шлюза из [настроек интернет-терминала](#terminal) |
    | **Тестовый режим** | Включите для тестовых логина и пароля, выключите для рабочих |
    | **Тип контрольной суммы уведомлений** | Тип, который назвал банк: **Симметричный (HMAC-SHA256)** или **Асимметричный (SHA512withRSA)** |
    | **Ключ проверки уведомлений** | Ключ от банка: секретный ключ для симметричного типа или открытый ключ (сертификат) для асимметричного |

    Комиссию, время ожидания платежа и поля заказа настройте так же, как для [любого способа оплаты](payment-providers.md#creating-a-method).

3. Нажмите **Сгенерировать тестовую ссылку для оплаты** и откройте ссылку. Для **Сбербанк** должна открыться страница оплаты Сбера, для **СБП (Сбербанк)** — страница оплаты через СБП. Если вместо ссылки появилась ошибка, проверьте логин, пароль и **Тестовый режим**: тестовые данные работают только при включённом режиме, рабочие — при выключенном.
4. Нажмите **OK** и выберите **Сохранить неактивным**.

## Проверка и запуск { #launch }

Тестовая ссылка проверяет только логин и пароль и не создаёт заказ в CRM. Уведомления и смену статуса проверьте настоящим заказом.

1. Если проверяли тестовые данные, введите рабочие логин и пароль, выключите **Тестовый режим** и снова проверьте тестовую ссылку.
2. Включите способ только в нужном магазине или сети: **Каталог → Магазины** → магазин → **Изменить** → **Управление способами оплаты** → **Сохранить**. Подробнее — в разделе [Способы оплаты](stores-and-delivery.md#payment-methods).
3. Оформите на сайте небольшой заказ с этим способом и оплатите его.
4. Проверьте, что заказ в CRM получил [статус «Оплачено»](orders.md#online-payment), платёж на ту же сумму виден в СберБизнесе, а покупатель получил чек, если отправка чеков подключена.
5. Если проверочный платёж нужно вернуть, [оформите возврат](orders.md#cancellation) отдельно.

Если ссылка на оплату не открывается или заказ не получил статус «Оплачено», выключите способ в магазине и напишите в [поддержку Tellem](https://t.me/tellem_tech_bot). Вопросы о договоре, терминале и уведомлениях задавайте менеджеру банка или ищите ответы в [справке СберБизнеса](https://www.sberbank.ru/help/business/sbbol).
